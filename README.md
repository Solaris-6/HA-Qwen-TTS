# Qwen3-TTS Project

Qwen3-TTS Home Assistant Integration

## Installation

```bash
# Using HACS
1. Add repository: https://github.com/Solaris-6/Qwen3-TTS
2. Search for Qwen3-TTS and install

# Manual installation
mkdir -p /config/custom_components/qwen3_tts
git clone https://github.com/Solaris-6/Qwen3-TTS /config/custom_components/qwen3_tts
```

## Supported Languages

- Italian (it) - Default
- English (en) - Default
- Chinese (zh)
- German (de)
- Portuguese (pt)
- Spanish (es)
- Japanese (ja)
- Korean (ko)
- French (fr)
- Russian (ru)

## Configuration

After installation, go to:
**Settings → Devices & Services → Add Integration → Qwen3-TTS**

Configure:
- Model path: Where your Qwen3-TTS model is located
- Voice: Default voice
- Language: Default language
